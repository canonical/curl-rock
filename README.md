# Curl Rock

A distroless-like curl image based on Ubuntu.

## Chiselled image

This image was created with [Chisel](https://documentation.ubuntu.com/chisel) to reduce the content of this image to only the essentials. This creates a more compact image with a smaller overall attack surface. Details on the content of this image can be found under the `curl_bins` slice(s) in the [chisel-releases](https://github.com/canonical/chisel-releases)
repository.
